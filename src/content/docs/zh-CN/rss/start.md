# 订阅说明

本站提供 RSS 2.0 订阅源，你可以在任意阅读器中添加订阅地址，新文章会自动出现在阅读器里，无需再回到站点翻看首页。

## 订阅地址

```text
https://lisris.com/feed.xml
```

所有访客页面的 `<head>` 中都带有订阅源声明，多数阅读器直接输入站点域名 `https://lisris.com` 也能自动找到上面的地址。

## 内容范围

| 项目 | 规则 |
| --- | --- |
| 收录文章 | 最新 20 篇已发布的公开文章 |
| 正文 | 全文，包含标题、图片、代码块和表格 |
| 摘要 | 文章的摘要，摘要为空时取正文开头 |
| 元信息 | 发布时间、作者、分类、标签、封面图 |
| 不收录 | 草稿、定时未发布、设为私有的文章 |

文章链接指向站内原文页面，代码块保留着色，但阅读器不会套用本站样式，正文以基础排版呈现。

## 更新规则

订阅源每 5 分钟重新生成一次。新文章发布后最迟 5 分钟进入订阅地址，之后阅读器按自己的轮询周期拉取，通常几分钟到几小时不等。

## 添加方式

| 阅读器 | 操作 |
| --- | --- |
| Feedly | 左侧栏选择 Follow feeds，粘贴订阅地址 |
| Inoreader | 顶部选择订阅，粘贴订阅地址 |
| Follow | 首页输入框粘贴订阅地址或站点域名 |
| NetNewsWire | 菜单选择添加订阅，粘贴订阅地址 |
| Miniflux | 订阅页面选择导入，粘贴订阅地址 |

## 已知限制

正文由区块编辑器排版时，依赖实时查询内容的区块不会出现在订阅源里，例如最新文章列表、评论流水线和日历。这类区块在订阅条目中会被跳过，文章其余部分不受影响。
